# Исследование партнёрок: Leads Market vs ServiceLead

> **Статус решения:** оставляем **только Leads Market**. ServiceLead **не подключаем**;
> этот документ сохранён как справочный — если вернёмся к вопросу второго канала.

**Статус:** исследование от открытых источников, без доступа в кабинеты.
**Дата:** см. историю файла. **Все спорные утверждения помечены источником.**
Документ нужен для выбора провайдера и подтверждает необходимость архитектуры
со сменными адаптерами (`LeadProvider`, см. `../PLAN.md` §6).

---

## 0. Главный вывод

| | Leads Market | ServiceLead |
|---|---|---|
| Технически | Чистая модель интеграции, есть «pulse» по гео | Богаче инструменты (свои ленды, пул номеров, API/postback) |
| Гео | 60+ городов | **170+ городов** |
| Ставки | фикс до 1200 ₽ / % до 26% | **до 3000 ₽**, средняя 700–1200 ₽ |
| Репутация 2026 | нейтральная, отзывы в целом позитивные | **критическая: публичные обвинения в невыплатах** |

**Рекомендация:** Leads Market — основной провайдер для MVP. ServiceLead — только как
**вторичный/экспериментальный** канал с ограниченным объёмом и контролем выплат.
Архитектуру строим так, чтобы провайдера можно было сменить/добавить без переписывания лендов.

## 1. ServiceLead — что это (проверено)

### 1.1 Идентификация
- Публичный сайт: **`servicelead.ru`** (маркетинг, офферы).
- Личный кабинет / API: **`servicelead.top`** и `manager.servicelead.top`.
- Это **один и тот же оператор**. Подтверждается:
  - отзывом партнёра на partnerkin: *«ServiceLead (он же сервислид.ру, сервислид.топ, servicelead.ru, servicelead.top)»*;
  - исторической документацией API (VK, 2019): endpoint `https://api.servicelead.top/`;
  - обоими доменами на Let's Encrypt, кабинет `.top` за nginx.
- **История бренда:** ПКП (Первая компьютерная помощь) → ФСС / «Федеральная служба сервиса» (`fss.su`) → **ServiceLead**.
  В отзывах также упоминаются «Сервис+», «РосБытСервис».
- Работает **с 2009 года**, прямой рекламодатель, полный цикл (свой call-центр, мастера).
- По заявлениям сайта: **170+ городов** РФ, филиалы в Беларуси и Украине, СНГ.

### 1.2 Офферы и ставки (с сайта `servicelead.ru`)
| Оффер | Выплата |
|---|---|
| Мастера БТ / Курсы мастеров БТ | от 3000 ₽ (HR-оффер) |
| Дезинсекция / Дезинфекция | до 3000 ₽ |
| Ремонт крупной БТ на дому | до 2300 ₽ (средняя 939 ₽) |
| Выездной ремонт холодильников | до 2300 ₽ |
| Ремонт стиральных / посудомоечных машин | от 706 / от 1000 ₽ |
| Компьютерная помощь на дому | средняя 739 ₽ |
| Ремонт телевизоров / электроники / кофемашин | от 1000 ₽ |
| Мастер на час | от 606 ₽ |

**Условия (по обзорам):** CPA/CPO, холд **24 часа**, выплаты **еженедельно**,
конверсия в заявку ~78–80%, первый вывод после 10 конверсий.
⚠️ Данные о минималке расходятся: `affmoment` пишет о минимуме 10 000 ₽,
`cpamafia` — что минималки нет. **Требует проверки в кабинете.**

### 1.3 Инструменты интеграции (важно для нашей фабрики)
- Свои **готовые лендинги и лид-формы**, плагин для **WordPress**.
- Подключение своих сайтов через **API** и **Postback**.
- **Пул телефонных номеров-приёмников** для голосового трафика → свой колл-центр 24/7.
- Конструкторы: Tilda, LP, Creatium, Wix; интеграции VK, FB, Marquiz.
- Telegram-бот для приёма лидов.
- Понятие **«поток»** (flow): 1 поток = 1 оффер (аналог нашего `landing`).

### 1.4 API ServiceLead (из документации 2019 г., CompLead API)
- Протокол: **JSON-RPC 2.0**, только HTTPS.
- Endpoint: `https://api.servicelead.top/` (в примере — `/ct`).
- Авторизация: `Authorization: Basic <base64>` или `Bearer <firebase-token>`.
- Методы:
  - **`addorder`** — создать заявку. `params`: `branch_id`, `fullname`, `phone`,
    `is_pm`, `work` (описание проблемы), `street`, `house`, `building`, `flat`,
    `is_lk`, `is_call`.
  - **`getbranches`** — список филиалов/городов (аналог «pulse»/гео).
  - `addpart` — регистрация партнёра (в старом примере).
- Ответ: `{"jsonrpc":"2.0","result":true,"id":1}`; ошибки в `error.code` (`-32602` — невалидные поля).

> ⚠️ Документации **7 лет**, кабинет с тех пор переписан. Формат «потока» и токены
> почти наверняка изменились. **Считать API-спеку неактуальной до проверки в кабинете.**

## 2. Репутация ServiceLead — сигналы риска (важно!)

### 2.1 Свежие обвинения в невыплатах (2026)
- **vc.ru, ~2 недели назад** — пост «Партнерка Servicelead (бывшая FSS) кинула вебов в 2026»:
  - комиссия начисляется, но **деньги не платят с июля 2026**;
  - утверждения про ООО «на дропах», расчёты наличными, объёмы «3,5 млрд ₽/год»;
  - ссылки на расследования (сайт «База» — уже недоступен, есть в вебархиве; «Дейлишторм»);
  - утверждение об **уязвимости**: партнёрский ID/данные были видны в коде формы.
  - Технический подрядчик партнёрки назван как ООО «Вайскод» (`vicecode.ru`).
- **partnerkin.com, детальный кейс (аккаунт ID 30534)**:
  - на балансе **77 326 ₽**, выплата тянулась с августа 2026;
  - менеджер в переписке признаёт **«кассовый разрыв»** и предлагает партнёру *дать новый
    трафик*, чтобы «закрыть сложности с выплатами»;
  - сроки многократно переносятся («понедельник–вторник» → «сегодня-завтра» → «ближайшие недели»).
  - Partnerkin помечает отзыв как «субъективное мнение пользователя».
- **gembla.net:** ретроактивно введён **лимит 3 заявки/день**, «срезаны» почти все
  подтверждённые кондиционерные лиды, переписка чистилась со стороны партнёрки.
- **cpamonstro:** жалобы на задержки выплат «с июня», поддержка «кормит завтраками».

### 2.2 Старые сигналы (этические)
- **pikabu, 2021** — пост о предложении «стать [мастером]» с наценками за настройку Windows
  (10–20 тыс. ₽), критика в адрес servicelead со стороны автора.

### 2.3 Позитивные/нейтральные источники
- `servicelead.ru`, `cpagram.ru` (2021), `cpamafia.top`, `affmoment.com` — хвалят надёжность,
  ставки, call-центр, инструменты.
- ⚠️ Многие из них — **партнёрские обзоры со ссылками `?utm_cod=...`**, т.е. заинтересованы
  в регистрации читателя. Как независимое подтверждение надёжности не годятся.
- `afftimes.com` — нейтральная карточка: средняя выплата 700–750 ₽, холд 24 ч, еженедельно.

### 2.4 Как трактовать
Это **не доказанное мошенничество**, а **серия однотипных публичных претензий 2026 года**,
включая подтверждённую менеджером формулировку «кассовый разрыв». Для пассивной SEO-фабрики,
где выручка копится месяцами, а выплаты — еженедельные, такой профиль риска **неприемлем как
основной канал**. Решение — только после личной проверки кабинета и тестовой выплаты.

## 3. Leads Market vs ServiceLead — сравнение для нашей задачи

| Критерий | Leads Market | ServiceLead |
|---|---|---|
| Домен/кабинет | `leads-market.ru` / `cpa.leads-market.ru` | `servicelead.ru` / `servicelead.top` |
| Бэкенд | `omni.business-controller.one` | `api.servicelead.top` (JSON-RPC) |
| Приём заявок | `leads_url` (токен в URL) | API (`addorder`) / формы / postback |
| Обратные статусы | `webhook_url` | Postback |
| Гео-документ | **есть `pulse`** (XLSX + API) | нет публичного, только `getbranches` |
| Города | 60+ (64 отдела в pulse) | 170+ |
| Ставки | до 1200 ₽ / до 26% | до 3000 ₽ |
| Холд | не подтверждён | 24 ч (заявлено) |
| Выплаты | еженедельно (заявлено) | еженедельно (заявлено) |
| Свои ленды/формы | интеграции amoCRM/Bitrix/Tilda/WP | готовые ленды, формы, WP-плагин, номер-пул |
| Колл-центр | да (услуги) | свой 24/7 |
| Риск 2026 | низкий/средний | **высокий (невыплаты)** |

## 4. Что это меняет в плане

1. **Адаптер `LeadProvider` обязателен** (см. `../PLAN.md` §6): Leads Market — первый адаптер,
   ServiceLead — второй, включается конфигом без правок лендов.
2. Добавить в модель `affiliate` поля **риск-профиля**: `payoutReliability`, `maxExposure`,
   `payoutHold`, `lastPayoutAt`, `isPrimary`, `enabled`.
3. **Правила роутинга:** основной (Leads Market) → резерв (ServiceLead) только для пар,
   которых нет у основного, и с лимитом.
4. **Мониторинг выплат:** дашборд «начислено / выплачено / просрочено» по каждой партнёрке.
5. **Не дублировать персональные данные** между партнёрками; минимизировать хранение.
6. Решение по ServiceLead принимать после: доступа в кабинет → тестовой заявки →
   **фактической первой выплаты**.
