# Avito-инструменты: build vs buy

После ссылки на `profile.reyting.pro` (Reyting Pro) и обзора рынка. Вывод: **операционку Avito
(масспостинг, уникализация, чаты, продвижение) покупаем готовым сервисом**, а свой софт строим
только для того, чего нет ни у кого — матрица `pulse`, контент под наши направления,
атрибуция звонков и аналитика выплат партнёрки.

> Цены и фичи — по открытым обзорам (2026), могут меняться. Многие статьи со ссылками-рефералками.

---

## 1. Что закрывает Reyting Pro (`reyting.pro` / `profile.reyting.pro`)

SaaS на Next.js, «сервис автоматизации продаж через Авито». Публичный список возможностей:

- **Автозагрузка объявлений** (`ruchki.reyting.pro`) — массовое размещение и управление из одного места.
- **Центр сообщений Авито** — переписка в разных аккаунтах в одном окне.
- **Чат-боты Авито** — автоответы по ключевым словам/времени/задержке.
- **Автоответы на отзывы через ИИ.**
- **Быть в сети** — аккаунт всегда онлайн (повышает конверсию).
- **Генератор оффера** и **генератор текста объявления** нейросетями.
- **Автостратегия** — автоматическое управление продвижением.
- **Интеграция с amoCRM** — сделки и диалоги из Авито.
- **Уведомления о балансе**, калькуляторы (ROI/ROMI/LTV/CPL…).

**Итог:** сильный слой «объявления + сообщения + продвижение + CRM».
**Не покрывает:** генерацию/уникализацию **фото**, управление **аккаунтами/прокси**, матрицу
«направление × город», атрибуцию **звонков** и аналитику **выплат партнёрки**.

- **Уникализацию фото** реально дают AviTool, AviForce, A5Client, МАССПОСТИНГ — то есть свою

- Все упираются в **тариф и лимиты Avito** — это внешнее ограничение, софтом не обходится.

## 3. Чего не закрывает никто (наш слой — то, что стоит строить)

1. **Матрица из `pulse.xlsx`** — направления × города со статусами и стоп-факторами.
   Это наш уникальный вход, ни у одного Avito-сервиса его нет.
2. **Контент под нашу вертикаль** — брифы по 16 направлениям, «что не делаем», локальная
   специфика, город в заголовке, проф. тексты под интент ремонта.
3. **Атрибуция звонков** — номер + партнёрский ID, привязка к аккаунту/направлению/городу,
   учёт звонков в разрезе объявления.
4. **Связка с партнёркой** — статусы лидов, апрув, выплаты из Leads Market.
5. **Аналитика ROI** — не «расход на Авито», а **чистая прибыль = выплаты − (Avito + аккаунты +
   прокси + AI)**, по направлению/городу/аккаунту. Ни один Avito-сервис этого не считает.
6. **Переключение партнёрки** (адаптер) — если конфликт/невыплаты.

## 4. Рекомендуемая связка (buy операционку, build уникальное)

```
pulse.xlsx ─▶ [НАШ слой: матрица + генерация текстов/фото + брифы]
                     │  (XML/Excel или напрямую в аккаунт)
                     ▼
        [Готовый сервис: AviTool / AviForce / Reyting Pro]
        (масспостинг, уникализация, чаты, продвижение, аккаунты)
                     │
                     ▼
        [НАШ слой: номер+ID → Leads Market, учёт лидов и выплат, ROI-дашборд]
```

Наш софт = **тонкая надстройка**, а не попытка переписать AviTool.

## 5. Обновлённый roadmap (короче и дешевле)

| Фаза | Что делаем | Кто закрывает |
|---|---|---|
| **0. Пилот** | 1 направление × 5 городов: наши тексты+фото, загрузка через готовый сервис | наш скрипт + купленный SaaS |
| **1. Ядро** | `pulse`→матрица, генератор контента, учёт номеров | наш софт (Strapi) |
| **2. Аналитика** | дашборд: лиды, апрув, выплаты, расход, ROI | наш софт (Next.js) |
| **3. Масштаб** | десятки аккаунтов, авто-бюджеты, авто-замена банов | SaaS + наш оркестратор |

**Экономия:** не пишем с нуля масспостинг, уникализацию, чат-ботов и управление аккаунтами —
это уже есть за 1 000–10 000 ₽.
